# AGENTS.md

This file is the primary working agreement for Codex and other coding agents operating in this repository.

## External-link validation

- Validate every external link from the user's local computer before adding it to repository content or presenting it to the user. Do not rely solely on model memory, search-result text, bibliographic metadata, or a URL reported by a third-party index.
- Open or retrieve the exact URL, follow redirects, and confirm that the final page exists, represents the resource described, and is not an error page, parked domain, advertising page, or unrelated destination.
- Where practicable, verify both the technical HTTP response and the visible page content. An HTTP 200 response alone does not establish that a link is correct.
- For Digital Object Identifiers (DOIs) and scholarly sources, confirm that the destination title, authors, or another unambiguous identifier matches the citation.
- If access requires authentication, is region-restricted, or cannot be tested from the local computer, label the link as not fully verified; do not describe it as a working public-access link.
- Before publication, run a local link check across the complete rendered site and manually investigate every error, redirect, and ambiguous result.

## Scientific content

- Write public-facing knowledge-base content in scientific English.
- Use linked author-date citations for scientific claims and distinguish measured evidence from interpretation, design inference, and developer claims.
