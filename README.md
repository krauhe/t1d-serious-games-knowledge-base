# T1D Serious Games Knowledge Base

This independent project will provide a scientifically documented knowledge base for the discovery, design, evaluation, and long-term maintenance of serious games relevant to type 1 diabetes education and self-management.

The project is currently a local private scaffold. Scientific content will be written in English. T1D Simulator will be treated as one product among other games and will be assessed using the same evidence, provenance, availability, and sustainability criteria.

## Local literature policy

Lawfully accessible full texts are stored locally in `private-literature/articles/`. The complete `private-literature/` directory is excluded by `.gitignore` and must not be pushed to GitHub. Bibliographic metadata, stable links, retrieval status, and access limitations belong in the tracked `references/` directory.

Third-party screenshots without documented republication permission are stored locally in `figures/game-images-review-only/`, which is also excluded from Git.
