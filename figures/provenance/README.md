# Figure and Image Provenance

## Original figures

Original figures created for this knowledge base must state their interpretive scope and any important simplifications. Unless explicitly stated otherwise, they are covered by the project's CC BY 4.0 licence.

## Published third-party figures

Any third-party figure included in the repository must have documented republication rights. Its record must state:

1. source URL;
2. capture or retrieval date;
3. stated or inferred copyright holder;
4. reuse status; and
5. the required attribution, where applicable.
